## D. 做板建议（参考）

- 主立绘 3072×5504 比例 1:1.79 → 60×107mm 或 50×90mm 板面正好；丝印层按 1:1 看脸是否还能辨认。
- 同人立绘细节多（褶皱、蕾丝、发丝），转 PCB 前建议先降为 4~6 色硬边色块，否则丝印会糊。
- 工程服版「安全帽 + CLAUDE 工装」语义最贴 PCB（工程师感），可做主视觉。
- Q 版 57 张 → 40×40mm 小徽章板，一张板排 6~9 个，露铜 + 蓝阻焊对比最好。
